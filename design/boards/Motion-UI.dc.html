Gerak: membuat layar hidup dan informatif
Dua belas gerak, masing-masing punya alasan. Demo di bawah berulang terus supaya mudah dibandingkan. Jeda semuanya dengan kotak di kanan.
Gerak menjawab satu pertanyaan
Apa yang baru saja terjadi? Gerak hanya muncul saat keadaan berubah: berhasil, gagal, menunggu, tersimpan. Tidak ada gerak untuk hiasan.
Cepat, lalu diam
Sebagian besar gerak 120 sampai 320 ms. Hanya centang berhasil sampai 600 ms, dan hanya sekali. Orang yang sibuk tidak boleh menunggu animasi.
Bisa dijeda dan dimatikan
Gerak yang berulang lebih dari 5 detik punya tombol Jeda. Bila perangkat meminta gerak dikurangi, semua berpindah ke keadaan akhir tanpa perjalanan.
Tenang di hal serius
Lapor TPPK, keluar otomatis, dan galat berat tidak bergetar, berkedip, atau bergoyang. Nada yang tenang membuat orang percaya.

Cara memasang
/* tokens.css (dihasilkan dari tokens.json) */
:root {
  --motion-cepat: 120ms;  --motion-biasa: 200ms;
  --motion-masuk: 320ms;  --motion-rayakan: 600ms;
  --ease-masuk: cubic-bezier(.2, .8, .2, 1);
  --ease-keluar: cubic-bezier(.4, 0, 1, 1);
}
/* Hanya animasikan transform dan opacity. */
.banner-in { animation: banner-in var(--motion-biasa) var(--ease-masuk) both; }

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
Hindari
  • Gerak memantul, goyang berulang, atau konfeti. Presensi itu urusan serius.
  • Gerak yang menunda tindakan. Tombol aktif seketika; gerak berjalan sambil orang bekerja.
  • Animasi tata letak (lebar, tinggi, margin). Pakai transform dan opacity saja.
  • Gerak otomatis lebih dari 5 detik tanpa tombol Jeda. Pada panel merek di layar masuk ada tombol itu.
  • Berkedip lebih dari 3 kali per detik. Kursor kotak kode berkedip 1 kali per detik.
  • Pustaka animasi besar. Semua gerak di sini cukup dengan CSS.
